# Financial Control System

This project is a **financial control system developed in Python**, designed to automate the registration of financial transactions and balance calculations using Excel spreadsheets as a data source.

The system was created to support small operations, such as the daily financial management of a restaurant or small business.

---

## 📌 Features

- Financial transaction registration:
  - Customer
  - Amount
  - Date and time
  - Transaction type
  - Observations

- Balance calculations:
  - Daily balance
  - Monthly balance
  - Individual balance per customer

- Modular and organized code structure
- Reading and writing data from Excel spreadsheets

---

## 🛠️ Technologies Used

- **Python**
- **Excel** (as data storage)
