# Sistema de Controle Financeiro

Este projeto consiste em um sistema de controle financeiro desenvolvido em **Python**, com o objetivo de automatizar o registro de movimentações financeiras e o cálculo de saldos utilizando planilhas do Excel como base de dados.

O sistema foi pensado para atender pequenas operações, como o controle financeiro diário de um restaurante ou comércio de pequeno porte.

---

## 📌 Funcionalidades

- Registro de movimentações financeiras  
  - Cliente  
  - Valor  
  - Data e hora  
  - Tipo da transação  
  - Observações  

- Cálculo de saldos:
  - Saldo diário  
  - Saldo mensal  
  - Saldo individual por cliente  

- Organização modular do código  
- Leitura e escrita de dados em planilhas do Excel  

---

## 🛠️ Tecnologias Utilizadas

- **Python**
- **Excel** (como armazenamento de dados)
- **Git e GitHub**
